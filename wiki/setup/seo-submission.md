# SEO Submission Checklist

## Google Search Console
1. Go to search.google.com/search-console
2. Add property: dementia.cyrilsebastian.com
3. Verify via DNS TXT record in Cloudflare
4. Submit sitemap: https://dementia.cyrilsebastian.com/sitemap.xml
5. Request indexing for the homepage

## Bing Webmaster Tools
1. Go to bing.com/webmasters
2. Add site: dementia.cyrilsebastian.com
3. Import from Google Search Console (saves time)
4. Submit sitemap
